Still open

Four things I cannot answer, and how each gets settled

Can a blocking wait observe a gate you don't own?

axi run blocks but triggers a run; attach opens a TUI that would hang an agent. There may be no non-polling observer API at all. Test: throwaway branch, trivial diff, start a gate, try to observe from a second terminal. The risk to avoid is a duplicate run.

What enforces "user-only, never model-invoked"?

user-invocable is a real frontmatter field. Whether the converse is enforced or only discouraged by wording is unverified — and three skills depend on it for safety.

Graphify's regeneration cost

One measurement. Seconds → adopt as designed. Full project scan → the gate's rebase cadence makes it expensive.

Does observe.py miss domain-modeling?

It never listed it, and the glossary check reads unreachable. Either the detector is blind or no glossary was written. Settle it before trusting that scorecard row again.
