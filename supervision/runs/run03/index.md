# Run 3 findings -- index

One row per finding in `findings.md`. **The id is authoritative, the line number
is a fast path.** Corrections append, so line numbers are stable in practice --
but if one is stale, `grep -n 'F-0NN' findings.md` settles it.

```
grep '| gate ' index.md          # every gate finding
grep 'confirmed' index.md        # skip the unproven and the corrected
```

**Drift check** -- these two must agree:

```
grep -c '<!-- F-[0-9]' findings.md
grep -c '^| F-[0-9]'   index.md
```

Do not narrow the pattern to `F-0` -- it stops matching at `F-100` and
under-counts both sides into false agreement.
